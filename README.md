# UDUS Study Hub

Build a sleek, modern, mobile-first academic portal dashboard for university students called 'UDUS Study Vault'. Include a top navigation header with the portal title, a live search bar for course codes, and level tabs (100L, 200L, 300L, 400L).

Add these standout features:

Anonymous Peer Discussion / QA Section: An embedded, log-in-free discussion board on each course card where students can ask questions, share tips, or drop anonymous past-question hints without revealing their identity.

Offline-First Reading Mode: A fast, zero-lag inline PDF viewer with text-selection protection, right-click disabling, and a semi-transparent 'UDUS Study Vault' watermark overlay.

Study Streak Tracker: A localized daily reading counter on the dashboard that rewards students for returning daily to study.

Past Question Quick-Quiz Mode: An interactive flashcard or quick-quiz toggle for major general courses (e.g., GST).

Request a Handout Button: A quick floating action button allowing students to anonymously request missing course notes.

Add a subtle, clean footer at the bottom reading 'Powered by BIG T Digital Solutions'."
